### ✧ About This Space
This is a custom-built personal corner of the internet. It was created to serve as a digital diary and portfolio, blending aggressive, sleek brutalist UI elements with soft, cute, and dynamic animations. 

Why build it? To experiment, to show off my Godot and Luau projects, and to have a dedicated space for myself and my partner, Envy ♥.

### ✧ Features
- **Custom UI:** Handcrafted CSS with glassmorphism, aggressive borders, and smooth hover-gradients.
- **Interactive Music Player:** A fully functional, slide-out brutalist music player.
- **Typewriter Animations:** timed, dual-typewriter effects that loop.
- **Custom Cursors:** A slide-out panel to instantly swap between custom glowing dots and expanding crosses.
